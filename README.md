# Ironvale community

The public home for [Ironvale](https://ironvale.pages.dev), a free tower defense
game that runs in the browser.

- **Found a bug?** [Report it](https://github.com/Lancimator/ironvale-community/issues/new?template=bug_report.yml)
- **Have an idea?** [Request a feature](https://github.com/Lancimator/ironvale-community/issues/new?template=feature_request.yml)
- **Want to talk?** [Discussions](https://github.com/Lancimator/ironvale-community/discussions): reviews, strategies, campaign stories, questions

The game's source is not in this repository; this is only where players and the
developer talk.

## House rules

1. Be decent to each other. Disagree with ideas, not people.
2. Nothing illegal, hateful, sexual, or harassing, and no personal information
   about anyone, yourself included.
3. No spam, advertising or links to cheats for other games.
4. Reviews are welcome whether they are good or bad. Negative reviews are not
   removed for being negative; posts are only removed for breaking these rules.
5. Write in English if you can, so everyone can follow.

Breaking the rules can get a post hidden or removed, or an account blocked from
this repository. Whenever that happens you are told which rule it was.

## Reporting a post

- **Breaks the house rules:** use GitHub's *Report content* option in the `…`
  menu of the post.
- **Illegal content**, or anything that needs to reach the operator privately:
  use the contact details in the
  [legal notice](https://ironvale.pages.dev/impressum.html). Reports are
  acted on as quickly as possible.

and [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
